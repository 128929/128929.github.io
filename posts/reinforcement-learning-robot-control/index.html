强化学习与机器人运动控制：从传统控制到四足机器人 Sim2Real

这篇笔记来自一次机器人运动控制技术培训，并在原始讨论基础上做了工程化整理与概念校正。目标不是复述会议，而是建立一套可以长期复用的知识框架：机器人为什么需要传统控制、强化学习解决什么问题、奖励函数如何影响行为，以及策略如何从仿真真正部署到机器人。

2026-08-24 约 18 分钟 知识沉淀
一句话结论：机器人并不是“传统控制”和“强化学习”二选一。实际工程更常见的是分层组合：底层电机环路保证确定性和高频实时性，上层运动控制负责约束与协调，强化学习 Policy 负责在复杂状态空间中产生更灵活的动作策略。

1. 先建立整体技术地图

机器人智能控制可以从两个维度理解：一是“学习方法”，二是“控制层级”。把这两个维度分开后，很多容易混淆的概念会清晰很多。

人工智能 AI
└─ 机器学习 Machine Learning
   ├─ 传统机器学习：SVM / 聚类 / 树模型 ...
   ├─ 深度学习 Deep Learning：神经网络自动学习表示
   └─ 强化学习 Reinforcement Learning：通过交互与奖励学习策略
      └─ 深度强化学习 Deep RL：用深度网络表示 Policy / Value

在机器人系统中，另一个重要维度是控制层级：

任务 / AI 决策层
        ↓
运动策略 Policy / 行为生成
        ↓
运动控制：MPC / WBC / IK / 轨迹规划
        ↓
关节伺服：位置环 / 速度环 / 力矩环
        ↓
电机控制：FOC / 电流环
        ↓
执行器与机械系统

2. 机器学习、深度学习、强化学习到底差在哪

2.1 传统机器学习

传统机器学习通常需要较多人工特征工程，例如先提取频域特征、纹理特征、统计量，再交给 SVM、随机森林、聚类等算法。它同样存在训练过程，只是模型规模和特征学习能力通常比深度网络弱。

2.2 深度学习

深度学习通过多层神经网络直接从数据中学习表示。训练的核心是定义目标函数，通过反向传播和优化算法不断调整网络参数，使损失下降。

2.3 强化学习

强化学习的关键不在于“有没有数据”，而在于数据是通过智能体与环境交互产生的。智能体观察状态，执行动作，环境返回下一状态和奖励，算法再据此更新策略。

State s_t → Agent / Policy → Action a_t
   ↑                         ↓
   └──── Reward r_t + State s_(t+1) ← Environment
理解重点：监督学习更像“有标准答案的练习题”；强化学习更像“在游戏里不断尝试，并根据得分学习怎样通关”。

3. 传统机器人控制为什么仍然非常重要

传统控制依赖数学模型、约束、状态反馈和优化方法。它的优势是行为可解释、实时性明确、约束可控，非常适合机器人底层和安全关键环节。

方法核心作用机器人中的典型位置
PID根据误差闭环调节电机位置、速度、力矩等伺服环
MPC基于模型预测未来并在线优化轨迹跟踪、质心运动、足端约束
WBC同时协调多个自由度与任务约束四足/人形全身运动控制
轨迹规划生成连续、满足约束的目标轨迹关节、足端、机械臂路径

以四足机器人为例，传统步态可以明确规定对角腿交替、足端摆动轨迹、落脚位置和步频。这样做的优点是规则清晰，但遇到复杂地形、未知扰动时，需要越来越多的模型与规则来覆盖。

4. PID、FOC 与强化学习为什么不在同一层竞争

培训讨论中有一个很有价值的问题：既然强化学习能够学习策略，是否“万物皆可强化学习”，甚至直接替代电机控制？

工程上通常不这样做。底层电机控制要求高频、确定、可验证。FOC 的控制周期通常是 kHz 到几十 kHz 量级，MCU 主频则可能达到数百 MHz；这里真正关键的是控制回路的确定性和低延迟，而不是单纯模型是否聪明。

概念校正：“FOC 按 MHz 频率闭环”容易把 MCU 时钟频率与控制环更新频率混为一谈。实际系统中 PWM/电流环常在 kHz～几十 kHz 范围，具体取决于电机、驱动器与控制器设计。

因此一个更稳妥的工程结构是：

强化学习 Policy：给出期望动作 / 目标
            ↓ 50~500 Hz（示例）
运动控制层：约束、状态估计、全身协调
            ↓
关节伺服：PID / 力矩环
            ↓ kHz 级
FOC / 电流环
            ↓
电机

5. 强化学习为什么特别适合四足机器人运动

四足机器人有多个关节、接触切换、非线性动力学和不确定地面。完全依靠人工规则覆盖所有状态非常困难。强化学习的优势恰好在于：它可以在高维状态空间里，通过大量试错搜索一个能获得高累计奖励的策略。

典型策略输入可能包括关节角、关节速度、机身姿态、角速度、期望速度等；输出可以是关节目标位置、目标速度或目标力矩。

速度跟随平衡恢复抗扰动复杂地形步态协调

6. Reward Function：强化学习最关键的“行为定义”

奖励函数不是简单的“走得越远分越高”，而是在告诉智能体：哪些行为值得保留，哪些行为需要被抑制。四足机器人常见奖励项包括：

  • 速度跟随：实际线速度、角速度接近期望指令。
  • 姿态稳定：机身保持合理俯仰与横滚。
  • 足端行为：摆动腿抬到合理高度，支撑腿避免无意义滑动。
  • 对称性：左右腿动作保持合理镜像或节律。
  • 能耗与平滑：限制过大力矩、关节加速度和动作突变。
  • 生存奖励：避免摔倒、翻转和异常接触。

奖励项之间可能互相冲突。例如“转向时鼓励抬腿”和“直行时减少抬腿”对应不同目标，这也是奖励设计需要反复调试的原因。

7. 为什么训练主要发生在仿真环境

真实机器人训练成本高：摔倒会损坏机械件，电机和减速器会磨损，大量重复实验也很耗时。物理仿真可以把大量试错转移到 GPU 上，并且并行运行很多机器人实例。

常见平台包括 Isaac Gym / Isaac Lab / Isaac Sim、MuJoCo、Gazebo 等。环境中可以配置：

  • 重力、摩擦系数、质量和惯量；
  • 关节阻尼、执行器响应；
  • 平地、坡面、碎石、楼梯等地形；
  • 随机外力和碰撞；
  • 传感器和执行器噪声。
训练效率：训练时关闭可视化通常会明显提高仿真吞吐量，因为 GPU/CPU 不再承担画面渲染，计算资源可以更多地用于物理仿真和策略更新。

8. Sim2Real：真正困难的是从仿真走到真实世界

仿真永远只是现实的近似。机器人落地时会面对建模误差、电机死区、摩擦变化、结构柔性、通信延迟和传感器噪声。强化学习策略如果只“背熟”一个精确仿真环境，真实部署往往会失败。

8.1 域随机化（Domain Randomization）

训练阶段主动随机化物理参数，例如摩擦系数、质量、质心、外力、关节误差、噪声和时延，让策略无法依赖某一个固定环境。

每次 Reset / 每批环境
  ├─ 摩擦系数随机
  ├─ 质量与惯量随机
  ├─ 关节偏差随机
  ├─ 传感噪声随机
  └─ 外力方向/大小随机
          ↓
Policy 学到对参数变化更鲁棒的行为

8.2 扰动训练

训练过程中周期性施加随机方向和随机大小的推力，可以训练机器人在受扰后恢复质心速度、姿态和支撑状态。这样得到的策略通常比只在“完美环境”训练的策略更抗干扰。

9. Curriculum Learning：把复杂任务拆成“关卡”

直接把楼梯、斜坡、扰动、速度跟随全部塞给一个随机初始化策略，可能导致学习难度过高。课程学习的思想是：先解决简单任务，再逐步提高难度。

阶段 1：平地稳定站立/行走
      ↓
阶段 2：扩大速度范围 + 小扰动
      ↓
阶段 3：坡面 / 不同摩擦
      ↓
阶段 4：楼梯 / 越野 / 更强扰动

它与深度学习里的“预训练再微调”在直觉上相似：前一阶段学习到的能力可以作为下一阶段的初始策略，但强化学习中的数据仍然由当前策略与环境交互产生。

10. 模仿学习：专家示范与策略学习之间的桥梁

模仿学习给机器人提供专家轨迹，让策略先学会“像专家一样做”，再通过强化学习进一步优化。它特别适合机器人操作和人形动作，因为从完全随机动作开始探索往往代价很大。

专家演示 / 动捕 / 遥操作
          ↓
Behavior Cloning / Imitation
          ↓
获得可用初始策略
          ↓
Reinforcement Learning 继续优化

11. 从“盲走”到感知运动：视觉、雷达、触觉如何接入

只使用本体状态的运动策略，本质上像“闭着眼睛走路”。机器人可以依靠 IMU、关节状态维持平衡，但面对楼梯边缘、落脚区域、障碍物等需要提前感知的场景，就必须引入外部感知。

完整系统可以理解为：

                 AI / 任务决策（大脑）
                        ↓
      ┌─────────────────┼─────────────────┐
      ↓                 ↓                 ↓
运动控制（小脑）      感知            定位与导航
      ↓          相机/雷达/触觉       SLAM / Path
执行器与机械体          ↓                 ↓
      └────────────── 信息融合 ────────────┘

短期可采用“视觉识别场景 → 自动切换不同运动策略”的架构；更进一步则可以把深度图、高程图等感知信息直接作为策略输入，让一个策略根据地形主动调整落脚点。

12. 多策略还是一个大 Policy？

平地、楼梯、越野和抗扰可能使用独立策略，也可能训练进一个统一策略。这里并不是简单由“参数量大小”决定，更关键的是任务分布、观测信息是否充分、奖励是否兼容以及训练是否稳定。

方案优点难点
多策略切换训练简单、每个策略目标明确需要可靠的场景识别和切换逻辑
统一策略切换自然、系统更统一训练分布复杂，奖励和观测设计更困难
分层策略高层选技能，低层执行技能需要设计技能库和层级接口

13. 世界模型与机器人强化学习

世界模型可以理解为：模型内部学习“环境如何演化”。如果机器人能预测“执行这个动作后下一刻会发生什么”，它就可以在内部进行想象、规划和评估。

它和强化学习关系很紧密，但并不是简单属于某一个单一类别。现代世界模型通常会使用深度学习来学习状态表示和动力学，再与规划或强化学习结合。

值得继续学习：Model-based RL、Dreamer、Latent Dynamics、Vision-Language-Action、具身世界模型，都是从“只学动作策略”向“学习环境规律并规划”扩展的重要方向。

14. 从工程角度得到的几条结论

  1. 强化学习不是替代控制理论。机器人越靠近硬件底层，越强调确定性、实时性和可验证性。
  2. Reward 是需求规格的一部分。奖励写得不清楚，策略会找到“看起来得分高但并非我们真正想要”的行为。
  3. Sim2Real 不是训练后的最后一步，而应从训练设计阶段就考虑。
  4. 感知决定了运动策略能看到多少世界。没有地形观测，再强的策略也无法提前知道前方是台阶还是坑。
  5. 调试方法仍然是核心能力。训练曲线、观测量、奖励分项、接触力、质心状态、关节输出都需要可视化和逐层验证。

15. 推荐的学习路线

机器人基础
  ├─ 运动学 / 动力学
  ├─ PID / 状态空间 / 优化
  └─ Linux + Python + C/C++
        ↓
仿真
  ├─ URDF / MJCF
  ├─ MuJoCo / Isaac Lab
  └─ 传感器、接触、执行器模型
        ↓
强化学习
  ├─ MDP / Policy / Value
  ├─ PPO / Actor-Critic
  ├─ Reward Design
  └─ Domain Randomization
        ↓
机器人运动控制
  ├─ Locomotion
  ├─ State Estimation
  ├─ Sim2Real
  └─ 感知运动 Perceptive Locomotion

对于实际机器人研发，建议不要只学算法论文，而是从一个可运行的小闭环开始：先让模型在仿真中稳定站立，再做速度跟随，再加随机扰动，最后再做真实机器人部署。每一步都要有可观测指标。

16. 总结

机器人智能运动控制的发展并不是“传统控制 → 强化学习 → 全部由 AI 接管”的线性替代，而是不同技术在不同层级逐渐融合。传统控制提供稳定可靠的底座，深度学习提供强大的表示能力，强化学习提供基于交互的策略优化能力，感知与世界模型则让机器人开始理解更复杂的环境。

大脑：任务理解、决策、规划
            ↓
小脑：运动策略、平衡、协调
            ↓
神经与反射：实时控制、状态反馈
            ↓
身体：电机、关节、机械结构、传感器

真正有价值的能力，是能把这些层级串成一个稳定、可调试、可验证的机器人系统。
