# 机器人系统架构理解：从 MCU 到具身智能

## 1. 为什么需要理解机器人系统架构

机器人不是单一程序，而是多个层级协同工作的复杂系统。

一个完整机器人通常包含：

```
AI算法层
    ↓
任务规划层
    ↓
运动控制层
    ↓
实时控制层
    ↓
硬件驱动层
    ↓
执行器/传感器
```

## 2. 机器人中的核心计算平台

### 上位计算平台

例如：RK3588、Jetson 等。

主要负责：

- AI推理
- 图像处理
- SLAM定位
- 任务规划
- 人机交互

特点：

- 算力强
- 可以运行 Linux
- 适合复杂算法

### 实时控制平台

例如：STM32、GD32 等 MCU。

主要负责：

- 电机控制
- CAN通信
- ADC采集
- PWM输出
- 实时响应

特点：

- 延迟低
- 确定性强
- 适合闭环控制

## 3. 为什么机器人需要 MCU + SOC

简单理解：

SOC负责“大脑”，MCU负责“反射神经”。

例如机械臂：

```
RK3588
 |
 | CAN/EtherCAT/RS485
 |
MCU
 |
电机驱动
 |
关节运动
```

视觉算法可以允许几十毫秒延迟。

但是电机控制如果延迟不稳定，就会产生震动甚至失控。

## 4. 机器人通信体系

常见通信：

|协议|应用|
|-|-|
|UART|调试、简单设备|
|SPI|高速传感器|
|I2C|低速传感器|
|CAN|机器人总线|
|RS485|工业设备|
|EtherCAT|高性能运动控制|

## 5. 学习路线

建议顺序：

1. MCU基础
2. 通信协议
3. 电机控制
4. Linux机器人平台
5. ROS2
6. AI机器人

## 总结

理解机器人系统架构，是进入机器人研发的第一步。

未来机器人发展的核心方向：

- 更强算力
- 更实时控制
- 更智能算法
- 更丰富感知
