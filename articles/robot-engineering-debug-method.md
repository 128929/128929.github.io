# 机器人工程调试方法论：如何定位一个问题

## 为什么记录

机器人系统涉及机械、电子、软件和算法，出现问题时不能只看代码，需要建立系统化排查方法。

## 我的调试顺序

```
现象确认
 ↓
电源检查
 ↓
硬件连接
 ↓
通信参数
 ↓
协议分析
 ↓
软件定位
```

## 第一层：物理问题

检查：

- 是否供电
- 地线是否连接
- 信号方向是否正确
- 电平是否匹配

## 第二层：通信问题

例如CAN、UART、RS485：

检查：

- 波特率
- 数据格式
- ID
- 校验
- 收发方向

## 第三层：软件问题

包括：

- 驱动初始化
- 中断
- DMA
- 缓冲区
- 协议解析

## 工程经验总结

很多通信故障，最终原因并不是程序错误，而是系统之间没有正确连接。

优秀工程师需要同时理解：

硬件 + 软件 + 协议 + 工具。
