# 机器人控制系统理解：从位置控制到力控制

## 为什么记录

机器人控制是连接算法、硬件和机械结构的核心环节。学习机器人过程中，很多概念容易停留在公式层面，但真正应用时需要理解控制系统在整个机器人中的位置。

## 我的理解

一个机器人控制系统，本质是在不断完成：

感知当前状态 → 与目标比较 → 计算误差 → 输出动作 → 获取反馈。

形成闭环：

```
目标
 ↓
控制器
 ↓
驱动器
 ↓
执行器
 ↓
传感器反馈
 ↓
控制器
```

## 常见控制层级

### 位置控制

目标：让机构到达指定位置。

例如：机械臂关节旋转到30度。

### 速度控制

目标：控制运动快慢。

例如：电机按照指定速度运行。

### 力控制

目标：控制机器人与环境交互的力度。

例如：灵巧手抓取物体时，需要知道接触力。

## 工程中的理解

机器人通常不是单一控制环，而是多层组合：

- 上层：任务规划
- 中层：轨迹规划
- 下层：电机实时控制

例如：

SOC负责规划，MCU负责毫秒级控制。

## 总结

机器人控制的核心不是单纯调PID，而是理解整个闭环系统：

机械、传感、通信、计算、控制共同决定机器人性能。
