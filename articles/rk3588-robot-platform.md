# RK3588在机器人系统中的作用理解

## 为什么记录

机器人正在从传统控制系统向智能化系统发展，需要同时具备实时控制和高算力计算能力。

RK3588这类SOC平台正适合作为机器人上层计算平台。

## MCU与SOC分工

MCU负责：

- 电机控制
- 实时采样
- 底层通信

SOC负责：

- Linux系统
- AI推理
- 图像处理
- 高层算法

## 机器人中的典型架构

```
摄像头/传感器
       |
       |
RK3588
       |
CAN/EtherCAT/UART
       |
MCU控制板
       |
执行器
```

## 为什么需要Linux平台

Linux生态提供：

- 丰富的软件环境
- AI框架支持
- 网络能力
- 开发效率

## 我的总结

机器人不是单一芯片完成全部任务，而是通过不同计算单元协同完成。

SOC提供智能能力，MCU保证实时控制。
