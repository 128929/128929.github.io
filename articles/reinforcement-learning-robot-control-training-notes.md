# 三、机器学习与深度学习区别

## 3.1 机器学习

传统机器学习通常需要人工设计特征和规则。

流程：

```
数据
 ↓
人工提取特征
 ↓
算法计算
 ↓
输出结果
```

特点：

优点：

- 数据需求较低
- 可解释性较强

缺点：

- 依赖人工经验
- 面对复杂环境能力有限

---

## 3.2 深度学习

深度学习通过神经网络自动学习数据特征。

核心过程：

```
输入数据
 ↓
神经网络
 ↓
计算损失函数
 ↓
反向传播优化
 ↓
模型提升
```

与传统机器学习区别：

不是人为告诉模型规则，而是通过大量数据训练，让网络自动发现规律。

# 五、PID与底层电机控制理解

PID属于经典闭环控制方法。

基本结构：

```
目标值
 ↓
控制器
 ↓
执行机构
 ↓
反馈
 ↓
修正误差
```

例如：

目标角度：10°

实际角度：8°

误差：2°

控制器根据误差调整输出。

需要注意：

控制并不是越快越好，需要根据系统响应要求调整。

# 六、强化学习核心概念

强化学习是一种通过不断试错，根据奖励反馈学习策略的方法。

核心组成：

```
        环境 Environment
              ↑
              |
动作 Action ← Agent → Reward
```

机器人训练过程：

1. 执行动作
2. 获得反馈
3. 根据奖励调整策略
4. 不断优化

最终得到策略模型（Policy）。

---

# 七、奖励函数 Reward Function

奖励函数决定机器人什么行为是好的。

四足机器人训练中：

正奖励：

- 保持身体稳定
- 跟随速度指令
- 保持正确步态
- 降低能耗

负奖励：

- 摔倒
- 腿拖地
- 身体倾斜
- 运动异常

强化学习的核心就是设计合理的奖励机制。

---

# 八、仿真训练与 Sim2Real

强化学习通常不会直接在真实机器人上训练。

常见仿真平台：

- Isaac Sim
- MuJoCo
- Gazebo

仿真环境可以设置：

- 重力
- 摩擦力
- 外力
- 关节参数
- 地形

机器人可以在虚拟环境中大量试错。

---

# 九、Sim2Real现实部署问题

仿真和现实存在差异：

- 物理参数误差
- 电机响应差异
- 传感器噪声
- 摩擦变化

解决方法：

## 域随机化

训练时加入随机变化：

- 摩擦随机
- 外力随机
- 关节误差随机
- 传感器噪声

提高机器人适应能力。

# 十四、强化学习目前的问题

## 泛化能力

单个策略通常难覆盖所有场景。

可能需要：

- 多策略切换
- 视觉辅助判断
- 世界模型

## 模型规模

强化学习策略模型通常较小。

优势：

- 实时运行快

不足：

- 难覆盖所有复杂情况

# 十六、强化学习是否适合底层电机控制

理论上强化学习可以控制电机，但实际工程中通常不会替代底层控制。

原因：

电机FOC控制：

- MHz级频率
- 极高实时性
- 稳定性要求高

因此机器人控制通常采用：

```
AI策略层
 ↓
运动控制层
 ↓
PID / FOC
 ↓
电机
```

强化学习更适合：

- 运动策略
- 行为规划
- 高层决策
