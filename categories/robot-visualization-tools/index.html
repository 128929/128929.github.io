机器人可视化 / URDF 工具

把网页端机器人模型查看、URDF / Xacro / MJCF 加载、关节控制以及后续真实机器人联动相关的开源项目集中到一个分类里，方便后续做星际光年手、灵巧手和机器人上位机时快速查找。

1优先参考

Robot Viewer

网页端机器人模型查看器，功能完整，适合作为机器人上位机和 URDF 调试界面的基础工程。

  • 支持 URDF / Xacro / MJCF / USD
  • 关节控制、Visual / Collision
  • 惯量、质心、坐标轴、结构树
  • 基于 Three.js，适合二次开发
GitHub 源码
2增强版

ERMINE Robot Viewer

Robot Viewer 的增强 fork，加入更多控制、测量和机器人信息能力，更接近“模型查看 + 真实机器人联动”的方向。

  • URDF 检查与模型调试
  • 控制、测量、机器人信息
  • IK 等增强功能
  • 适合参考真实机器人联动架构
GitHub 源码
3底层组件

urdf-loaders

更底层的 URDF 加载库，适合自己设计网页 UI，同时复用成熟的 Three.js URDF 加载和关节控制能力。

  • Three.js / Unity URDF Loader
  • 支持 package:// 路径映射
  • 支持 joint angle 控制
  • 适合自定义机器人网页上位机
GitHub 源码
使用建议：如果目标是尽快做出完整的机器人模型查看与控制界面，优先从 Robot Viewer 改；如果更关注 IK、测量和真实机器人联动，可以重点参考 ERMINE；如果准备完全自定义界面和交互，则把 urdf-loaders 当作底层加载组件更合适。
